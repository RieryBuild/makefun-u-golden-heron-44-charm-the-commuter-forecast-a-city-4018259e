One line of weather for Sablemere, a city that does not exist — rain until
nine, then bright spells, ducks grounded, commuters still running to
schedule. A broadcast-forecast register with a small joke for a bored
commuter at a rainy bus stop.

## Run it

```sh
python3 main.py
```

Writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
