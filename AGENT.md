# AGENT.md

## What this is

Entry for make.fun's "Charm the Commuter: Forecast a City That Isn't"
bounty. `main.py` writes a single one-line weather forecast (101
characters, no trailing newline) for Sablemere, a city that does not exist,
to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## How to run it

```sh
python3 main.py
```

Python standard library only. No network, no secrets, no arguments.
